File formats and next steps

CSV columns: time_s,II,V1,.... Use uniform timestamps in seconds and voltages in millivolts. JSON uses the documented Heartscope format. Browser WFDB import supports interleaved 16-bit records such as PTB-XL. Other WFDB layouts can be prepared with the Python converter in the project.

PDF and photo digitization are not included yet. Remove identifying information before sharing or exporting real patient data. Export preserves supplied metadata.
